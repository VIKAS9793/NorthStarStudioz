# Contributing to NorthStar Studioz

Thank you for your interest in **NorthStar Studioz** and **NorthStar MR**!

## Project Nature
NorthStar MR is a proprietary commercial mixed-reality game developed by **Vikas Sahani** for the **Meta Horizon Store**. While this repository provides open documentation, architecture, and web assets for transparency, the core game is an independently authored project.

## How You Can Contribute
* **Bug Reports:** If you spot an issue in the documentation, web portal, or open tooling, please open a detailed issue under [Issues](https://github.com/VIKAS9793/NorthStarStudioz/issues).
* **Feature Suggestions:** Share spatial mechanics, level concepts, or tactile ideas in GitHub Discussions or Issues.
* **Pull Requests:** Small fixes to documentation, typos, or accessibility improvements are welcomed!

## Code of Conduct
Please maintain a respectful, constructive, and collaborative tone in all interactions within this community.
