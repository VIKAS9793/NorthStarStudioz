# Contributing to NorthStar Studioz

Thank you for your interest in **NorthStar Studioz**!

## Project Nature
NorthStar Studioz is an independent game and spatial computing studio founded and led by **Vikas Sahani**, building experiences for the **Meta Horizon Store** and spatial platforms. While this repository hosts the official studio web portal, legal policies, and platform assets, all internal game design documents, roadmap plans, and proprietary game source code remain private.

## How You Can Contribute
* **Bug Reports:** If you spot an issue on the web portal or public guidelines, please open a detailed issue under [Issues](https://github.com/VIKAS9793/NorthStarStudioz/issues).
* **Feature Suggestions:** Share spatial ideas, accessibility recommendations, or feedback in GitHub Discussions or Issues.
* **Pull Requests:** Improvements to the web portal, styling, or accessibility are welcomed!

## Code of Conduct
Please maintain a respectful, constructive, and collaborative tone in all interactions within this community.
